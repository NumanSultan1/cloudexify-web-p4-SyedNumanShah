# Brew & Bite

A premium cafe and bakery restaurant prototype built as a static frontend foundation for future full-stack development.

## Restaurant concept

Brew & Bite is a warm, cinematic cafe and bakery concept centered around artisan coffee, fresh bakery favorites, breakfast classics, desserts, and an elevated neighborhood café experience in Deolai, Swat.

## Technologies currently used

- HTML5
- CSS3
- Vanilla JavaScript
- Bootstrap 5 via CDN
- Three.js via CDN for the 3D hero experience
- Static local assets and public image URLs

## Current development stage

This is a redesign and enhancement pass for the Step 1 foundation, with a premium 3D hero experience, richer menu content, and upgraded visual treatment while preserving the original frontend prototype structure.

## Planned future integration

The project is structured to later integrate with:

- Supabase Auth
- PostgreSQL database
- profiles table
- menu_items table
- orders table
- customer/admin role logic
- admin route protection
- live order status updates
- customer order history
- menu CRUD workflows
- dashboard statistics
- row level security

## Planned Vercel deployment

The static frontend is designed to remain compatible with deployment on Vercel as a static website while future backend features are added in later project steps.
